# Материалы карточки RuStore

Актуальный интерфейс 0.7.1, четыре вертикальных скриншота 1080×1920. Загружать по номерам: работа → редактор → готовые режимы → отдых в тёмной теме. Иконка 512×512, непрозрачная; соответствует drawable ic_timer приложения. Файлы PNG меньше 3 МБ. Источник скриншотов и контрольные суммы — source.json.

Тексты для полей лежат в отдельных TXT: name, short-description, description, whats-new. Кандидат категории — «Спорт», если доступна в консоли; возрастную категорию заполнить по анкете RuStore и фактической рекламе. Минимальная версия Android 8.0/API 26 определяется APK.

Описание подготовлено для запланированного выпуска с рекламой. Скриншоты сняты с preview без загруженной рекламы. Перед отправкой сверить описание и главную страницу с финальной конфигурацией. APK в этот набор не включён: 0.7.1 остаётся preview, поскольку контакты и production SDK IDs не заполнены.

Контакты, политика, параметры SDK и порядок завершения — ../../docs/PUBLISHING_HANDOFF.md. Не загружать старые скриншоты из соседнего ru/ вместо этого набора.

Требования сверены 20.10.2026 по https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication : название ≤30, краткое описание ≤80, полное ≤4000 символов; не менее трёх скриншотов, PNG/JPG до 3 МБ, максимальный размер 2160×3840; иконка 512×512 до 3 МБ без прозрачности. Проверка уникальности названия выполняется в консоли.
