# Материалы RuStore 0.7.3

Четыре оригинальных скриншота приложения на Android 16, 1080×1920 без системных панелей; иконка 512×512 с непрозрачным фоном. Название/описания в отдельных текстовых файлах. APK передаётся отдельно.

На скриншотах не загружена реклама; в публичной версии баннер доступен в меню и итоге. Скриншоты не изменялись графическим редактором. Источник и хеши — source.json. Актуальная политика — docs/privacy-policy.md в репозитории и в комплекте передачи.
