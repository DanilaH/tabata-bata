# Материалы RuStore для 0.11.4

Для загрузки в консоль:

1. Иконка — `icon-512.png` (512×512, непрозрачная). Побайтно совпадает с `drawable-nodpi/ic_timer.png` в исходниках подписанной APK 0.11.4.
2. Телефон — пять PNG из `phone/`, в порядке 01–05. Удалить прежние четыре изображения из черновика. Размер каждого нового файла 1080×1920 (9:16), менее 3 МБ.
3. Планшеты, обычное и фоновое видео можно пока оставить пустыми. Портретные снимки телефона не загружать как планшетные.

`preview.jpg` — только обзор комплекта; не загружать его вместо карточек.

В оформлении оставлены только крупные заголовки (110–120 px). Убраны мелкая подпись бренда, поясняющие строки, счётчик карточек и точки навигации. Читаемость проверена на превью шириной 176 px; содержимое снимков приложения сохранено побайтно в показанной области.

## Происхождение

Настоящие кадры приложения из успешного UI-аудита main 43266280411, artifact 13967411191 (`ru-normal`, Android 15, шрифт 100%). Production-код — `6ba22f03e50ae6063f713841878d254c35b06d35`. Сетевые тесты работали с demo-ID без продуктовой аналитики.

В карточках встроены исходные PNG, без перерисовки интерфейса. SVG viewBox обрезает системные панели Android; у карточки своих режимов дополнительно отсечена нижняя рекламная область. Названия режимов, цифры, тексты и управление не заменялись. В истории показан воспроизводимый пример занятия из тестового набора, а не статистика реального пользователя.

`source.json` фиксирует SHA256 исходников и итоговых PNG, координаты обрезки и происхождение. Оригиналы — в `source/captures/`, итоговые SVG — в `source/svg/`.

Повторная сборка из корня репозитория: `python3 scripts/store/render_0114.py` (Python 3, Pillow и Inkscape). Проверяется размер, непрозрачность иконки, длина заголовков и лимит файлов. Изменения не затрагивают APK, таймер, SDK или подпись. Медиа подготовлены к загрузке; публикация в магазине этим не подтверждается.
