# Материалы RuStore 0.7.5

icon-512.png — новая непрозрачная иконка 512×512. screenshots/ — четыре оформленные карточки 1080×1920, загружать в порядке 01–04. Тексты в отдельных TXT. Скриншоты телефона не загружать как планшетные.

Внутри карточек — оригинальные снимки приложения, без перерисовки элементов интерфейса. Их источник указан в source.json. С версии снимков интерфейс этих экранов не менялся; 0.7.4 исправила контейнер рекламы, 0.7.5 меняет иконку. Production-реклама на снимках отсутствует.

Верстка воспроизводится scripts/store/render_cards.py (Python, Pillow, Inkscape; DejaVu Sans). Иконка создана встроенным ImageGen, запрос — icon-prompt.txt; экспортирована в 512×512 и включена в APK как drawable-nodpi/ic_timer.png. Иконка уведомлений остаётся отдельным монохромным ресурсом Android.

Для публикации использовать подписанную APK 0.7.5, не прежнюю 0.7.4. APK передаётся отдельно; в этом наборе нет ключа подписи или SDK Secrets.
