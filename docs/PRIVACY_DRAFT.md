# Политика данных — черновик, не для публикации

До размещения заполнить имя/реквизиты оператора, адрес поддержки, дату, публичный URL; сверить фактический merged manifest и поведение подключённых SDK. Нельзя публиковать этот черновик как готовую юридическую политику.

Режимы тренировок и настройки хранятся локально. При экспорте пользователь сам выбирает файл/провайдера хранения Android. Названия режимов не входят в продуктовые аналитические события. Таймер не требует аккаунта, не запрашивает контакты, микрофон, камеру или точное местоположение.

При активации AppMetrica приложение передаёт события использования: начало и завершение/остановка таймера, диапазон плановой длительности, фактическое время активного отсчёта, число пауз и переходов, факт сохранения режима, обнаружение прерванной сессии. Используются случайные идентификаторы занятий; добавляется тип сборки и версия схемы. AppMetrica также обрабатывает технические данные и диагностическую информацию согласно своей документации. Отслеживание местоположения отключено в конфигурации.

При включении рекламы используется Yandex Mobile Ads; SDK может обрабатывать технические сведения об устройстве и рекламные идентификаторы. SDK добавляет соответствующие разрешения автоматически. Не обещать отсутствие идентификаторов/IP/приблизительных геоданных без отдельной проверки документации и сетевого поведения. Уточнить основания обработки, возможные способы управления персонализацией и применимые требования.

Удаление приложения удаляет его локальные данные. Экспортированные пользователем файлы остаются в выбранном им месте до самостоятельного удаления. Условия и порядок обращений о данных аналитики нужно связать с возможностями подключённого сервиса и фактическими обязанностями оператора.
