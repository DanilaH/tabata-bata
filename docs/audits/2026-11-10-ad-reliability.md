# Рекламная надёжность 0.7.6

Дата: 10 ноября 2026 (Екатеринбург). Исходный код: `6264042a279ef4babf92664e162fed2d86971f74`.

## Проблема и изменение

Экспорт AppMetrica: межстраничка 278 запросов / 264 ошибки загрузки / 10 загрузок / 0 показов. Код причины ранее не сохранялся: нельзя установить, что исходный отказ был именно no-fill, сетью или конфигурацией. Бесконечные повторы увеличивали число ошибок. Баннерный request фиксировал только явную начальную загрузку, а ответы также приходили от SDK refresh; точный fill rate из этих счётчиков не выводится.

Исправлены бесконечные повторы и бессмысленная загрузка после исчерпания дневного лимита. До трёх запросов с паузами 15/60 секунд; после отказов новый допустимый переход/foreground не ранее пяти минут может открыть следующую серию. Бюджет экземпляра Activity не объявляется глобальным сетевым лимитом. Background, тренировка, editor/settings и защищённые диалоги отменяют ожидание; незавершённый SDK-запрос не дублируется. Его успех может заполнить кеш, но никогда не запускает show. Кеш истекает по нашей консервативной политике 45 минут.

Prefetch после первой завершённой тренировки готовит показ для следующей. Показ только явным выходом с результата, никогда Stop/Repeat/late load. Первая тренировка защищена; 24 часа считаются по onAdShown и переживают перезапуск. Показанное объявление удерживается сильной ссылкой. Повторные и устаревшие load callbacks отклоняются токеном. Уничтоженные баннеры не присылают события от старой геометрии.

Schema 2: app_version, attempt, SDK load error code, show_attempt, shown, skipped.reason; banner request отмечен initial_load. Сырые SDK descriptions, ID блоков, ключи и названия таймеров не отправляются. Рабочие ID включены только в configured build; production-реклама в тестах не запускается.

Адаптированы lifecycle/geometry/diagnostics контракты mini-games-kit@a9325265e87583a4872cf6a158e1e881a0d7508e (docs/android/ADS_AND_LIFECYCLE.md, docs/layout/NATIVE_BANNER_PLACEMENT.md). JS/WebView координатные преобразования не нужны Compose-приложению. TimerService не привязан к рекламным lifecycle-блокировкам и продолжает тренировку в фоне.
