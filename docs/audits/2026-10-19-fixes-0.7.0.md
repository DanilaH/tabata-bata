# Проверка исправлений 0.7.0

Исправления относятся к независимому аудиту 0.6.1. Продуктовый код 61123b00098ea13ffe34e038cbf1fdbcd189dbc7 совпадает с кодом приложения в последующих тестовых коммитах 43ef5b78 и 306d07e3.

## Закрытые сценарии

- Атомарный лимит Store: последовательность 500 → удалить → скопировать → отменить не записывает 501-й режим; результат LIMIT показывается пользователю.
- Два одновременных добавления при 499 режимах: ровно одно SAVED и одно LIMIT, итог 500.
- Отмена удаления восстанавливает исходный индекс. Импорт и перестановка работают с актуальными данными внутри транзакции.
- Старые списки из 501 режима читаются без обрезания; новые добавления запрещены до освобождения места. Повреждённый JSON не перезаписывается, доступные записи можно экспортировать; пользователь получает сообщение. Дубли ID не передаются в LazyColumn.
- Возвраты к предыдущему этапу продлевают wake lock. После 12 секунд возвратов в шестисекундном занятии сервис RUNNING и блокировка удерживается.
- Объяснение разрешения уведомлений и ожидающий план сохраняются при пересоздании Activity; последующее нажатие «Позже» запускает занятие.
- На 320 dp обе кнопки ± имеют ширину 52 dp.
- При отмене удержания следующий семантический клик изменяет 27 → 28.
- Переход 1:01 → 59 сохраняет размер цифр 152.99539 sp.
- На 320 dp со шрифтом 200% значение 60:00 помещается в поле и кнопка запуска доступна.

## UI и отклик

Уплотнены готовые режимы, убраны дубли параметров и вложенные рамки редактора. Поле времени гибкое и адаптирует размер цифр к доступной ширине. Зарезервировано место под надпись паузы. Уточнены подписи этапов, Stop и ошибки лимита/импорта; серия 0/N не показывается. Сохранено синее оформление меню.

Короткие появления обычных экранов, смена цвета этапа и перестановка карточек используют Compose-анимации. Старт сервиса не ждёт анимации. +10 даёт галочку и доступное подтверждение, сохраняя постоянную подпись действия. Новых виброимпульсов при нажатиях нет.

## Проверки

- Аудит-регрессии: run 39308423559, PASS. 23 unit-теста, включая 1000 случайных планов и 150000 действий; 6 инструментальных сценариев API 35 с включёнными анимациями.
- Общий CI: run 39309227169, PASS всех пяти jobs. 22 unit-теста, lint, debug/release сборки; по 18 UI-тестов на API 35/36, debug/minified-release проверки процесса и восстановления; совместимость и обновление с 0.5.1 на API 26/35.
- Промежуточный прогон нашёл смену подписи +10, мешавшую стабильному поиску действия; исправлено.
- В двух прогонах API 35 тесты черновиков пропускали разные координатные нажатия при изменении компоновки клавиатурой. В тестах состояния используются явные семантические действия и синхронное предоставление разрешения. Проверки содержимого, сохранения, запуска и очистки черновика сохранены; отдельные smoke/hold-тесты продолжают проверять касания.
- Скриншоты сняты с фактического приложения, просмотрены светлая/тёмная темы, редактор, работа/отдых, настройки, landscape и увеличенный шрифт. Это эмуляторы, не физический телефон.
