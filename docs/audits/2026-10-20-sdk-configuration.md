## Уточнение demo-диагностики

Прогон 39412005995 подтвердил загрузку/показы, но координатный fallback попал по ссылке тестового объявления и открыл браузер; onAdDismissed не подтверждён. Координатный fallback удалён. Финальный диагностический тест включает FLAG_REPORT_VIEW_IDS и ищет реальные ресурсы SDK monetization_ads_close / monetization_ads_instream_skip либо точные доступные подписи; касается центра найденного элемента только внутри ru.tabatabata. Сохраняет дерево доступности, чтобы отсутствие кнопки было диагностируемым. Assertions закрытия и частоты не ослаблены.

Прогон 39412890056 сохранил дерево доступности: у кнопки story-креатива нет resource ID и contentDescription, хотя другие элементы SDK имеют ID. Тест дополнен структурным поиском по наблюдённому дереву: небольшой правый ImageView внутри строки с [DEMO AD]. Он ограничен ru.tabatabata и не нажимает тело объявления или CTA. Место определяется по текущим bounds узла, а не фиксированной координате.
