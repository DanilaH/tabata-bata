# Независимый предрелизный прогон 0.7.3 — 20.10.2026

Статус: технический прогон завершён, найденные блокеры исправлены. Кандидат подготовлен для загрузки. Публикация и получение событий в кабинете AppMetrica ещё не подтверждены.

## Подход

Повторно прочитаны ядро таймера, сервис, сигналы, хранилище, редактор, экраны, реклама/аналитика, manifest и CI. Расширены проверки пограничных состояний; выполнены полный CI Android 8/15/16, отдельные регрессии с анимациями, реальный demo SDK и minified offline smoke. Production-реклама в автоматических тестах не запускается, реальные объявления не нажимаются.

## Найдено и исправлено

1. Повреждённый checkpoint: JSON плана был защищён, но чтение index/remaining/completedWork выполнялось вне обработки ошибок. Восстановление могло уронить процесс. Теперь проверяется весь checkpoint; непригодная запись удаляется, пользователь получает сообщение, сохранённые режимы остаются доступны. Тестирует испорченный JSON, отсутствующие поля, неправильный список выполненных этапов и последующий обычный старт. Первый прогон этого теста выявил ForegroundServiceDidNotStartInTimeException: остановка без startForeground недостаточна. Сервис теперь выполняет foreground-контракт до проверки входа и снимает уведомление при отказе. Исправление перепроверено на API 26/35/36 — PASS.
2. Быстрый повтор: отложенная остановка сервиса предыдущего финиша могла сработать во время финиша следующего короткого занятия. Теперь предыдущая задача завершения отменяется при старте/восстановлении и перед назначением новой. Тест проверяет окно жизни foreground service после второго финиша; он не доказывает физическую слышимость.
3. Высота часов: исчезновение следующего этапа/уменьшение очереди в конце и появление номера серии меняли высоту области. Теперь пространство сохраняется без отрисовки скрытых строк и без скрытых accessibility-целей. Тест проходит все этапы двух серий, отдых между сериями и заминку с обоими режимами очереди.
4. Повреждённый черновик: синтаксически корректный JSON без обязательных полей падал при открытии редактора. Структура проверяется целиком; повреждённая заменяется исходными значениями, корректные незавершённые пользовательские поля сохраняются. Тест открывает повреждённый черновик и редактирует время.
5. Конструктор TimerEngine формировал интервалы до validate(). Для некорректных программно переданных огромных повторений это грозило чрезмерным выделением памяти. Валидация перенесена перед построением списка. Пользовательские импортируемые планы и раньше валидировались на входе; новый unit-тест защищает сам конструктор.

## Дополнительные проверки

- APK: apksigner verify PASS, прежний сертификат; zipalign с 16 KB PASS, PT_LOAD всех 8 native .so выровнены на 16384. Это статическая совместимость упаковки, не отдельный прогон на устройстве с 16 KB страницами.
- Lint debug/release: 0 ошибок, 35 предупреждений (новые версии SDK/плагинов, target SDK, неиспользуемые ресурсы/атрибут, KTX-стиль). Обновление всего набора зависимостей не смешивалось с исправлениями перед выпуском.
- RU/EN: одинаковые наборы ключей строк, пропусков нет.
- WAV: клиппинга нет; tick 0.11 с, finish 0.9 с. RMS исходного финиша 0.468 против 0.334 отсчёта; дополнительно отсчёт воспроизводится с коэффициентом 0.55. Это характеристики файлов/кода, не измерение динамика.
- Manifest: основной сервис не экспортирован, резервное копирование отключено, специальный foreground service объявлен. Дополнительные SDK-разрешения проверяются по merged manifest.
- Analytics: в событиях нет пользовательских названий; автоматический Ad Revenue не дублируется ручным вызовом. Получение данных в кабинете не проверено.
- Хранилище: атомарные изменения, лимит 500, undo с позицией, ограничение импорта 1 млн символов, повреждённые списки не перезаписываются автоматически; регрессии повторены — PASS.
- Сеть: основной таймер не ждёт загрузки рекламы; отдельный minified demo smoke отключает wifi/mobile data и проверяет старт, force-stop, обновление APK и ручное восстановление.

## Ограничения

Все автоматические Android-прогоны — эмуляторы. Обратная связь пользователя относится к 0.7.1, а не ко всем аппаратным сценариям для 0.7.3. Не подтверждены новым физическим протоколом Bluetooth, звонок, Xiaomi/HyperOS и длительная работа с выключенным экраном. Данные кабинета AppMetrica и прохождение модерации RuStore не подтверждены. Тест demo lifecycle использует изолированный Ads-компонент: не выдавать его за полный e2e реальной рекламы во всех экранах.
