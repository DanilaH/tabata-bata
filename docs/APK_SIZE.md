# Размер APK — 0.6.0

Размер подписанной APK в байтах, измерен после zipalign и apksigner:

| Версия | APK | Сжатый DEX | resources.arsc | res/ |
| --- | ---: | ---: | ---: | ---: |
| 0.5.1 | 13 638 774 | 11 871 550 | 976 100 | 388 820 |
| 0.6.0 | 5 303 968 | 3 938 476 | 598 368 | 372 072 |

Сокращение 8 334 806 байт (61,1%). Размер APK включает ZIP-заголовки, выравнивание и подпись, поэтому не равен сумме показанных строк. 5,30 MB = 5,06 MiB.

Причина исходного размера: release не включал minify/shrinkResources. R8 удаляет неиспользуемые классы/методы и оптимизирует оставшийся код; resource shrinking удаляет неиспользуемые ресурсы. SDK рекламы и аналитики не удалены из зависимостей, но их неиспользуемые части могут быть оптимизированы. По этим измерениям нельзя достоверно приписать каждому SDK отдельное количество мегабайт.

Звуки и графика не были основной причиной размера. Качество звуков ради уменьшения файла не снижалось. CI проверяет обычную debug-сборку и отдельный smoke minified release; реальные SDK IDs и аппаратная проверка остаются в RELEASE.md.
