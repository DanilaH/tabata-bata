# Подготовка первого выпуска — 20 октября 2026

## Текущее состояние

Функциональный кандидат 0.7.1 / versionCode 11 / ru.tabatabata. CI и регрессии пройдены, постоянная подпись проверена. Пользователь после предложенной проверки телефона сообщил: «по моему всё заебись». Это положительная общая обратная связь, но модель телефона, длительность фонового теста и результаты каждого сценария отдельно не сообщены. Не превращаем её в протокол PASS всех аппаратных проверок.

Материалы карточки: store-assets/rustore-0.7.1/. Название 30 символов, краткое описание 68, полное описание 1227. Четыре исходных PNG актуального приложения 1080×1920, иконка 512×512; без системных панелей. Без обещаний медицинского эффекта, отсутствия рекламы или полного отсутствия сбора данных.

## Данные от владельца

| Данные | Назначение | Куда передать при сборке |
| --- | --- | --- |
| Email поддержки | Публичный контакт, кнопка в настройках и обращения по данным | supportEmail |
| ФИО / наименование оператора | Точное имя ответственного в политике данных | В текст политики; не выводить из ника |
| Публичный HTTPS-адрес готовой политики | Кнопка в настройках и карточка | privacyUrl |
| AppMetrica API key приложения | Production-аналитика | appMetricaKey |
| Отдельный тестовый AppMetrica API key | Проверка событий без загрязнения production | appMetricaKey только в тестовой сборке |
| Yandex Mobile Ads banner ID | Баннер вне занятия | bannerId |
| Yandex Mobile Ads interstitial ID | Полноэкранный блок после занятия по ограничениям частоты | interstitialId |

Не нужны пароли от кабинетов, OAuth-токены управления или приватные ключи API. Нужны именно ключ SDK приложения и идентификаторы рекламных блоков. Keystore уже существует и повторно не создаётся. Данные сборки не коммитить в публичные файлы.

Если публичной страницы политики пока нет, сначала получить имя оператора и email, закончить docs/PRIVACY_DRAFT.md под фактическую конфигурацию SDK, затем разместить на выбранном владельцем публичном HTTPS-адресе и проверить открытие без входа. Черновик с незаполненными реквизитами не публиковать.

## Следующий технический проход

1. Собрать отдельную тестовую APK с demo-banner-yandex и demo-interstitial-yandex; analytics только с отдельным тестовым ключом. Проверить реальный загрузившийся demo-креатив и callbacks, а не только отсутствие падения.
2. Проверить баннер на главной/результате и отсутствие рекламы в редакторе, при старте, подготовке, работе, отдыхе и паузе. Первый успешно завершённый таймер не вызывает interstitial. На втором завершении он возможен только при «К режимам», если загружен. «Повторить», Stop, отсутствие сети/рекламы не должны ждать или вызывать поздний показ. После показа действует ограничение 24 часа.
3. В тестовом кабинете сверить workout_started, workout_finished, preset_saved, session_recovered и рекламные loaded/impression/closed/error. Проверить отсутствие названий режимов в событиях. Проверить автоматический Ad Revenue без ручного дублирования.
4. Сверить merged manifest финальной сборки и фактические данные SDK с декларацией RuStore и политикой. Исходный manifest не содержит всех SDK-разрешений.
5. Передать production IDs, supportEmail и privacyUrl; собрать финальный minified APK с новой версией и прежней подписью. Проверить установку поверх 0.7.1, сохранность режимов, доступность контакта/политики. Реальные объявления не использовать для тестовых кликов.
6. В RuStore заполнить сведения, контакты, анкету данных/возраста и загрузить материалы. Уникальность названия проверяется в консоли. Финальное размещение ещё не выполнено.

## Основа для объяснения разрешений

| Разрешение / функция | Зачем приложению |
| --- | --- |
| FOREGROUND_SERVICE / SPECIAL_USE | Пользовательский интервальный таймер продолжает отсчёт и сигналы при сворачивании приложения |
| POST_NOTIFICATIONS | Показывать текущий этап и управление таймером в уведомлении |
| WAKE_LOCK | Поддерживать активный отсчёт при выключенном экране; освобождается на паузе/при завершении |
| VIBRATE | Настраиваемые сигналы отсчёта и смены этапов |
| INTERNET | Рекламные и аналитические SDK; самому отсчёту интернет не нужен |
| Экспорт/импорт | Системный выбор файла Android, без запроса доступа ко всему накопителю |

Этот список основан на исходном manifest приложения. Добавленные SDK разрешения, идентификаторы и категории данных дополнить по финальному APK; не подавать эту таблицу как полную декларацию.

## Для модератора

Аккаунт и тестовые учётные данные не требуются. На главной можно запустить готовый режим либо создать собственный. Настройки содержат переключатели звука, вибрации и оформления. Приложение — инструмент отсчёта времени, без медицинских рекомендаций. Фоновый сервис запускается только пользователем для занятия, при аварийном прерывании восстановление требует явного действия.
