# Scope и roadmap

Цель: законченный небольшой Android-таймер, опубликованный в RuStore. Бесплатная установка, реклама вне занятия, без аккаунтов/сервера и платных сохранений.

Поводы выбрать: несколько своих режимов бесплатно, запуск одним нажатием, удобные короткие интервалы, понятные сигналы, отсутствие рекламы перед стартом/в занятии. Уникальность и коммерческий результат не подтверждены.

## Порядок

1. Ядро и воспроизводимая сборка: монотонное время, конечные этапы, тесты переходов.
2. Первая APK: редактор, режимы, управление и звуки.
3. Фон: сервис, уведомление, энергопотребление, музыка, Bluetooth и прерывания.
4. Сохранность: экспорт/импорт, обновление поверх предыдущей сборки.
5. Аналитика и рекламные SDK: события без названий/личного текста, тестовые рекламные блоки, контроль частоты.
6. Подписанная production-сборка, политика данных, обратная связь, иконка/скриншоты/карточка, модерация.

Произвольные последовательности, голосовые названия, история/графики, курсы, калории, облако, AI, часы и пульсометры вне первого релиза.

## Правила поведения

Последний отдых по умолчанию пропускается. Между сериями используется только отдых между сериями. Пауза сохраняет точный остаток; переход начинает выбранный этап целиком. Переход далее с последнего этапа завершает таймер. После существенной задержки не проигрываем очередь пропущенных сигналов. Отключение наушников ставит на паузу. Уничтожение процесса/перезагрузка не возобновляют занятие автоматически. Сохранённый остаток после аварийного прерывания имеет точность до интервала checkpoint (1 секунда).

Реклама: баннер в режимах/результате; interstitial только после завершённой тренировки, не первой, максимум один показ в 24 часа. Нет рекламы на редакторе/старте/подготовке/работе/отдыхе/паузе. Нет rewarded. Отсутствие рекламы/интернета не блокирует приложение.
