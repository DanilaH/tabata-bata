## Расширенная проверка 15 октября

GitHub Actions [38624650474](https://github.com/DanilaH/tabata-bata/actions/runs/38624650474): PASS, build/lint/12 unit tests, по 8 инструментированных тестов на Android 15/16 (API 35/36, x86_64, KVM). Production-код не менялся; расширены тесты и CI.

Проверено на эмуляторах:

- Настоящий короткий цикл подготовки/работы/отдыха до завершения, без ускорения часов.
- Пауза/продолжение через реальные PendingIntent кнопок опубликованного уведомления. Остаток на паузе не уменьшается.
- Activity в состоянии CREATED, экран выключен: остаток продолжает уменьшаться; после завершения уведомление и recovery-checkpoint удаляются.
- Уведомления заблокированы через AppOps: таймер запускается и завершается. Это не проверка пользовательского диалога отказа разрешения.
- Ручное восстановление checkpoint: сначала диалог без самозапуска; восстановленная сессия остаётся INTERRUPTED с сохранённым остатком до явного продолжения.
- Системный шрифт 150%, landscape: редактор загружается, старт/пауза/завершение доступны с прокруткой.
- В отдельном adb-процессе после инструментированных тестов: запуск тренировки, настоящий am force-stop, отсутствие foreground service, сохранение checkpoint; adb install -r той же APK сохраняет DataStore побайтно и checkpoint. Повторное открытие показывает recovery-диалог без запуска сервиса.

В первых прогонах тест поворота искал кнопку до окончания перезагрузки редактора. Исправлены ожидания загрузки и применение системного шрифта в тесте; production-код не правился. Все финальные сценарии выполнены на обеих версиях Android.

Ограничения: короткий screen-off прогон не подтверждает 30–60 минут работы на реальном телефоне; same-version reinstall не является проверкой миграции между версиями. Аппаратная слышимость, Bluetooth, музыка/звонки, TalkBack, перезагрузка устройства, доставка AppMetrica и demo-реклама здесь не проверялись.
