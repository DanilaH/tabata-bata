# Проверки

## Автоматическое ядро

- 5 + 2/2 ×25 без последнего отдыха =103 сек.
- 5 + 8/5 ×10 без последнего отдыха =130 сек.
- Серии без двойного отдыха.
- Переход ровно на deadline, позднее пробуждение и завершение.
- Длительная пауза не уменьшает остаток.
- Нулевые опциональные этапы, опциональный последний отдых.
- Переходы при паузе остаются на паузе.
- Восстановление требует ручного продолжения.
- 5/5 ×23: переход на 13-й цикл.
- Общая длительность совпадает с суммой этапов.

## Обязательное перед production

- Реальный Xiaomi/HyperOS и другой Android: выключенный экран 30–60 минут.
- Музыка: ducking вкл/выкл, звонок, возврат из другого приложения.
- Bluetooth: колонка/наушники, отключение, выход из зоны связи.
- Отказ разрешения уведомлений, mute/низкая системная громкость.
- Обновление APK поверх старого с режимами/настройками.
- Force stop/перезагрузка: нет самозапуска и неожиданного звука.
- Экспорт/импорт, невалидный JSON, слишком большой файл.
- Крупный системный шрифт, landscape, TalkBack.
- Сетевая ошибка рекламы/аналитики не мешает таймеру.

Эмулятор не доказывает звук, Bluetooth и энергопотребление на физическом устройстве. Результаты фактических проверок добавляются ниже, без приписывания непроведённых тестов.
