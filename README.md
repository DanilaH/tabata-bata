# Табата Бата

Небольшой Android-интервальный таймер для RuStore. Kotlin, Jetpack Compose, Material 3. Android 8+ (API 26), target/compile API 36.

## Сборка

Нужны JDK 17 и Android SDK. Укажите SDK через `ANDROID_HOME` или `sdk.dir` в локальном `local.properties`.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions выполняет проверки и сохраняет APK как artifact.

## Реализованный scope

Подготовка/работа/отдых/повторения; серии и отдельный отдых между ними; заминка; опциональный последний отдых. Сохранение, копирование, перестановка и удаление с отменой. Экспорт/импорт JSON v1. Крупный таймер с цветом этапа и полоской его прогресса под цифрами, отдельной landscape-компоновкой и опциональной очередью этапов; пауза, переходы, блокировка управления. Редактор с ±1, вводом секунд или мин:сек и закреплённой длительностью/действиями. Черновики отдельно от сохранённых режимов, защита от потери изменений, возврат к черновику после занятия. Итоговое активное время и уникальные полностью выполненные рабочие раунды с учётом пауз/пропусков и восстановления. Короткие оригинальные звуки, вибрация, опциональные сигналы 3/2/1 для этапов от 6 секунд. Удержание экрана по выбору. Foreground service `specialUse`, управление уведомлением, монотонные часы, partial wake lock только во время активного занятия. Восстановление прерванной сессии на паузе. Русский и английский интерфейс. Светлое, тёмное и системное оформление с сохранением выбора. Готовая табата 20/10 × 8 доступна на главной без создания режима.

Режимы остаются на устройстве. Перед удалением приложения нужен экспорт. Ограничение в 500 режимов защищает размер импорта/хранилища, оно не платное.
